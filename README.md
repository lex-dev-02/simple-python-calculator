# Simple Python Calculator

This is a simple calculator written in Python.

The program asks the user to enter two numbers and choose an operator.

The calculator can perform the following operations:

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

## How it works

1. The user enters the first number.
2. The user chooses an operator.
3. The user enters the second number.
4. The program calculates and prints the result.

## Technologies used

- Python
